## Test quality assessment

`test_grapheme_matching_available` is a genuine test, not a placeholder: it asserts both halves of
the R20.2 contrast (1 cluster vs 3 codepoints) and would fail if `regex` were replaced by `re` or
dropped from the dependency set. That is exactly the regression that would silently break every
metric downstream, so this is the right thing to pin at the toolchain layer.

`test_package_imports` asserts `importlib.import_module(name) is not None`, which the QA checklist
names as a weak form. In practice `import_module` raises on failure so the test does verify
importability, but the assertion communicates nothing. Low severity only.
